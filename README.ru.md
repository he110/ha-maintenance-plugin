# Maintainable для Home Assistant

[![Открыть репозиторий в HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=he110&repository=ha-maintenance-plugin&category=integration)
[![Добавить обслуживаемый компонент.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=maintainable)

Напоминания о том, что требует регулярного ухода, но само об этом не скажет: картриджи
фильтра для воды, фильтры очистителя и бризера, щётки пылесоса, чистка от накипи, ТО машины.

Когда подходит срок, напоминание появляется в разделе **Настройки → Ремонт** — там же, где
Home Assistant показывает свои предупреждения, — и там же отмечается выполненным.

[English version](README.md)

## Что создаётся

Для каждого компонента:

| Сущность | |
|---|---|
| `sensor.<имя>_m_status` | `ok` / `due` / `overdue` |
| `sensor.<имя>_m_days` | Дней до обслуживания; при просрочке — отрицательное число |
| `sensor.<имя>_next_maintenance` | Дата следующего обслуживания |
| `date.<имя>_last_maintenance` | Последнее обслуживание — меняется прямо на странице устройства |
| `button.<имя>_maintenance_button` | Отметить обслуженным сегодня |

- **Ремонт:** предупреждение, когда срок близко, ошибка — когда прошёл. Кнопка **Исправить**
  спрашивает, когда обслужили, и отсчитывает следующий срок от этой даты. Проблема исчезает сама.
- **Привязка к устройству:** фильтр — на странице своего очистителя, а не отдельным устройством.
- Статус пересчитывается в полночь по часовому поясу Home Assistant.
- Интервал, срок напоминания и устройство можно поменять в любой момент.

## Контроль батарей

Добавляется один раз: *Добавить интеграцию → Maintainable → Батарейки всех устройств*. Настраивать
каждое устройство не нужно — интеграция сама находит все батарейки в доме, включая устройства,
добавленные позже, и сообщает о севших в разделе «Ремонт»: **предупреждение при 10% и ниже**,
**ошибка при 0%**. Напоминание исчезает, когда батарею заменили.

- Одно напоминание на устройство (по самой разряженной батарее). Процент важнее флага «батарея
  разряжена» от производителя — флаг учитывается только у устройств без процентов.
- Телефоны, планшеты и часы (`mobile_app`) по умолчанию не отслеживаются. В *Настроить* —
  пороги и исключения интеграций или отдельных устройств.
- `sensor.low_battery_devices` — сколько устройств требуют внимания; список — в атрибуте `devices`
  (имя, заряд, серьёзность, сущность), удобно для дашбордов.

## Установка

**HACS:** кнопка **Open in HACS** вверху (или HACS → ⋮ → Custom repositories →
`https://github.com/he110/ha-maintenance-plugin`, категория *Integration*), установить, перезапустить Home Assistant.

## Добавление компонента

Кнопка **Add integration** вверху или *Настройки → Устройства и службы → Добавить интеграцию →
Maintainable*. Одна запись интеграции — один компонент.

| Поле | |
|---|---|
| Название | Например, «HEPA-фильтр — очиститель в спальне» |
| Интервал обслуживания | Как часто, в днях |
| Напоминать заранее | За сколько дней до срока статус станет `due` (по умолчанию 7) |
| Последнее обслуживание | Если пусто — сегодня |
| Устройство | Необязательно: показывать компонент на странице этого устройства |

Потом: *Настроить* — интервал, срок напоминания и показ в разделе «Ремонт»; *Изменить* —
название и устройство. ID сущностей при этом не меняются.

## Автоматизации

Сервисы `maintainable.perform_maintenance` и `maintainable.set_last_maintenance` (с полем
`maintenance_date`) — цель: любая сущность компонента. События `maintainable_due`,
`maintainable_overdue`, `maintainable_completed` приходят при смене статуса (не при каждом
перезапуске). Примеры — в [английском README](README.md#automations).
